Half-Life Co-op 0.4.6 для Windows

КООПЕРАТИВНАЯ КАМПАНИЯ

Основной режим начинается с поездки в Чёрную Мезу на c0a0
Дальнейший путь до финала задают оригинальные переходы карт Half-Life
Можно играть одному на сервере с двумя слотами и затем подключить товарища

Реализованы перенос инвентаря и состояния мира между картами, возрождение
у контрольной точки, общие сюжетные события и сохранения всей сессии
Оружие и костюм выдаются по сюжету
Получение HEV и модуля long jump распространяется на группу
Урон товарищам по умолчанию включён
В 0.4.5 значение mp_friendlyfire 1 задано в серверной DLL и coop.cfg
Для отключения выполните mp_friendlyfire 0 в консоли хозяина
Для сохранения выбора между картами измените строку в установленном hlcoop/coop.cfg

АВТООБНОВЛЕНИЕ В 0.4.6

start-hlcoop.cmd проверяет свежий стабильный GitHub Release перед запуском игры
Адрес публичного репозитория задаётся в update.json как "repository": "owner/repo"
Пока репозиторий не создан, поле оставлено пустым и запускается установленная версия
При недоступном GitHub также запускается установленная версия
Обновление применяется при закрытой игре, существующие настройки и сохранения остаются
Для отключения проверки установите "enabled": false в update.json
Для уведомлений без установки используйте "mode": "notify"
Прямой запуск hl.exe и запуск игры самим Steam обновлятор не вызывает
Хозяину и товарищам сначала нужно открывать start-hlcoop.cmd, затем подключаться
Для выпуска обновления нужны новый номер версии и опубликованный Release с ZIP/SHA256
Одного обновления исходников на GitHub недостаточно
Инструкция автора находится в исходном проекте: docs/AUTO_UPDATE.md

ПЕРЕХОДЫ И ПОЯВЛЕНИЕ ИГРОКОВ В 0.4.4

Инициатор сохраняет положение относительно landmark и свою скорость
Остальные сохраняют положение только внутри заданной картой trigger_transition
Иначе товарищи появляются рядом с инициатором в свободном месте
Каждый сохраняет своё снаряжение, скорость отставшего игрока сбрасывается
Это исправляет появление отставшего игрока над пустотой следующей карты
Защита от обратного перехода отсчитывается от появления каждого игрока
Попадание в обратный портал во время задержки блокирует возврат до выхода из него
На c2a5c закрытие двери входной камеры больше не возвращает группу автоматически
Пассажиры поезда появляются с запасом между корпусами для прохождения поворотов
Сюжетные телепорты выбирают свободное место у выхода или ждут его освобождения
Небольшое несовпадение пола у landmark исправляется с проверкой пола и корпуса
Общая поправка применяется и к появлению товарища после засады перед компактором

ИСПРАВЛЕНИЕ МЫШИ В 0.4.3

При m_rawinput 1, если движок не включил относительный режим SDL,

Игрок подтвердил восстановление свободного обзора после этой команды
Автоматический переход 0.4.3 ещё предстоит проверить у товарища после обновления
Клиентская и серверная DLL 0.4.3 успешно собраны в Release Win32
Серверная DLL совпадает с обычной сборкой 0.4.2, ввод изменён в клиентской DLL

УСТАНОВКА И НОВАЯ ИГРА

Нужна установленная оригинальная Half-Life из Steam
Распакуйте hlcoop-0.4.6-win32.zip рядом с hl.exe и папкой valve
Либо скопируйте туда папку hlcoop из game в исходниках
Оригинальные карты, модели и звуки используются из установленной игры

Откройте start-hlcoop.cmd внутри установленной папки hlcoop
Он запускает главное меню мода и подходит хозяину и товарищу
Хозяин создаёт или продолжает сессию, товарищ принимает приглашение Steam
Проектные .cmd запуска Half-Life и scripts/launch.ps1 всегда добавляют -insecure
Флаг выбирает сервер без VAC и не гарантирует отсутствие банов по другим причинам

Для обновления из исходников нажмите F6 в текущей игре и закройте Half-Life
Затем запустите update-and-continue-steam.cmd из папки исходников
Он обновит мод, сохранив конфигурации, затем продолжит quick со Steam Networking
Файлы .hcs сохраняются, установщик откажется обновлять работающую игру
Принудительного завершения игры нет

В папке исходников доступны:
start-campaign.cmd — новая кооперативная кампания
start-coop.cmd — тот же основной режим
continue-campaign.cmd — продолжить quick, либо autosave, если quick отсутствует

Для запуска мода укажите в параметрах Half-Life:
-game hlcoop -console -insecure

В главном меню выберите New co-op campaign
Либо выполните в консоли:
exec newcampaign.cfg

Запуск новой кампании сразу через параметры Half-Life:
-game hlcoop -console -insecure +exec newcampaign.cfg

Новая кампания использует два слота, среднюю сложность и Steam Networking

ВЫБОР ГЛАВЫ ИЛИ КАРТЫ

Нажмите ESC → «Выбрать главу или карту» → вкладка «Game / Игра»
Выберите пункт в списке «Глава или карта», затем нажмите «Start / Начать»
Сначала идут названия 19 глав, затем полный список 96 карт с названиями глав
Здесь же можно выбрать сложность, число игроков и пароль сервера
По умолчанию выбраны начало кампании, средняя сложность и два слота
При прямом запуске поздних глав выдаётся стартовое снаряжение

Выбор начинает новую сессию на выбранном уровне
Быстрое сохранение quick и именованные сохранения остаются доступны
Продолжить их можно через Continue co-op game или coop_load
Файлы autosave и checkpoint будут перезаписаны автосохранением новой сессии

СОХРАНЕНИЯ И ПРОДОЛЖЕНИЕ

F6 — сохранить всю сессию: coop_save quick
F7 — загрузить всю сессию: coop_load quick
Для другого имени: coop_save chapter1 или coop_load chapter1
Имена используют латинские буквы, цифры, подчёркивание и дефис

Из игрового клиента сохранять и загружать может хозяин сервера в слоте 1
Загрузка возвращает всю группу и мир к сохранённому состоянию
Файлы находятся в hlcoop/save: coop_quick.hcs, coop_autosave.hcs
Автосохранение создаётся в подходящий безопасный момент
При гибели всей группы мод пытается восстановить контрольную точку сессии

В меню доступны Continue co-op game и Load co-op autosave
Continue загружает quick, а Load co-op autosave загружает autosave
Из консоли: exec continuecoop.cfg или exec continueauto.cfg
Эти конфигурации создают сервер и ставят загрузку сессии в очередь
Обычные одиночные файлы .sav загружаются только в отдельном режиме Campaign
Описание этого режима и скриптов установки находится в README.md исходников

ПОВТОРНОЕ ПОДКЛЮЧЕНИЕ И СОХРАНЕНИЯ

Инвентарь из .hcs восстанавливается владельцам по SteamID, в том числе при позднем входе
Чужое сохранение с другим SteamID не предназначено для одиночного запуска другим игроком
Старые LAN-сохранения STEAM_ID_LAN сопоставляются по игровому имени
При переходе на Steam Networking оставьте прежнее имя для восстановления своего инвентаря
После успешного появления текущий личный инвентарь не кешируется при выходе с сервера
При повторном входе без ожидающей записи .hcs берётся набор живого товарища
Восстановление ожидающего инвентаря владельца из .hcs поддерживается

ПОДКЛЮЧЕНИЕ ТОВАРИЩА

На обоих компьютерах установите ту же сборку мода и запустите Steam
По умолчанию используется Steam Networking: sv_lan 0, sv_use_steam_networking 1
Хозяин начинает или продолжает кооперативную сессию и приглашает товарища через Steam
Товарищ принимает приглашение или присоединяется через список друзей Steam
Перед подключением у товарища должен быть запущен наш мод:
Откройте hlcoop/start-hlcoop.cmd либо используйте параметры Half-Life:
-game hlcoop -console -insecure
Если уже открыта обычная Half-Life или другой мод, закройте его и запустите hlcoop
В окне выбора главы или карты за этот режим отвечает флажок Steam Networking

Для обычной локальной сети снимите флажок Steam Networking при создании сервера
Товарищ подключается командой connect ЛОКАЛЬНЫЙ_IP_ХОЗЯИНА:27015
Для Radmin VPN подключитесь к одной виртуальной сети
На LAN-сервере с выключенным Steam Networking хозяин один раз выполняет sv_lan 0
Товарищ подключается командой connect RADMIN_IP_ХОЗЯИНА:27015
Для прямого подключения через интернет также нужен доступ к серверу

В исходниках scripts/launch.ps1 поддерживает -Network Steam, -Network Lan и -Network Direct
Steam используется по умолчанию, Lan выбирает локальную сеть, Direct подходит для Radmin VPN
Параметр Network применяется только к кооперативному режиму
Выбранный сетевой режим сохраняется при сюжетных переходах и загрузке .hcs
Конфигурация coop.cfg не меняет сетевые параметры на каждой карте
Команды продолжения в игровом меню сохраняют текущий сетевой режим

Для смены сетевого режима сохраните сессию клавишей F6 и закройте игру
В исходниках продолжите прогресс командой:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\launch.ps1 -LoadSave quick -Network Steam -Windowed
В журнале 0.4.2 подтверждено подключение второго настоящего клиента через Steam на c1a0d
Переходы и сохранения с двумя настоящими клиентами, а также полное совместное
прохождение ещё предстоит проверить
