Half-Life Co-op 0.4.11

Кооперативный мод для оригинальной Half-Life: кампания от поездки
в Чёрную Мезу до финала. Рассчитан на двоих, но можно играть одному
и подключить друга позже.

Мод ещё в разработке. Полное прохождение вдвоём пока не проверено:
в отдельных сценах и переходах возможны ошибки. Сохраняйтесь вручную.

Установка

Нужна оригинальная Half-Life из Steam для Windows. Half-Life: Source
не подходит. У обоих игроков должна быть одна версия мода.

1. Скачайте HLCoopLauncher.exe из последнего релиза:
   https://github.com/Gena97/half-life-coop/releases/latest
2. Положите EXE куда удобно, например на рабочий стол, и откройте его.
   Он найдёт Half-Life, установит мод и запустит игру.
   Если папка не найдена или установок несколько, выберите нужную.

Для следующих запусков открывайте этот же EXE. Не удаляйте его после
установки: он запускает мод и обновляется в той папке, где лежит.
Ярлыки не создаются. Настройки и сохранения остаются.
Уже установленный мод переустанавливать вручную не нужно.

Если используете ZIP, распакуйте папку hlcoop рядом с hl.exe и valve,
а затем откройте hlcoop/start-hlcoop.cmd. Это ручной способ установки.

Карты и остальные ресурсы берутся из установленной Half-Life.

Как играть с другом

Запустите Steam и откройте HLCoopLauncher.exe на обоих компьютерах.
Хозяин выбирает «New co-op campaign» для новой игры или
«Continue co-op game» для продолжения быстрого сохранения.
Затем приглашает друга через Steam. Друг принимает приглашение
или присоединяется через список друзей.

По умолчанию включён Steam Networking. Обычная Half-Life у друга
должна быть закрыта: перед подключением нужно открыть именно мод.
Запуск использует -insecure: сервер работает без VAC.

Начать с другой главы

Нажмите Esc → «Выбрать главу или карту» → вкладка «Game / Игра».
В списке сначала идут главы, затем все карты кампании.
Выберите нужную, задайте сложность и нажмите «Start / Начать».

Это начинает новую сессию. Быстрое и именованные сохранения остаются,
но автосохранение и контрольная точка будут заменены по ходу новой игры.

Сохранения

F6 — сохранить всю сессию, F7 — загрузить её.
Сохранять и загружать может хозяин. Загрузка откатывает всю группу
и мир к сохранённому состоянию.

Быстрое сохранение: hlcoop/save/coop_quick.hcs.
Для отдельного сохранения откройте консоль (~) и введите:
  coop_save chapter1
Чтобы загрузить его:
  coop_load chapter1

Настройки и частые проблемы

Урон по товарищам включён. Чтобы отключить его, хозяин вводит в консоли:
  mp_friendlyfire 0
Чтобы оставить этот выбор на следующих картах, замените строку
mp_friendlyfire 1 на mp_friendlyfire 0 в файле hlcoop/coop.cfg.

Если мышь не даёт повернуться на полный круг, введите в консоли:
  m_rawinput 0

Обновления

HLCoopLauncher.exe проверяет новые версии мода и самого EXE
в GitHub Releases. EXE обновляется на своём месте. Если GitHub недоступен,
остаётся установленная версия.
Первый запуск без интернета установит версию, встроенную в EXE.

Запускатель устанавливает мод и обновляется без PowerShell и CMD.
Перед обновлением проверяются подпись проекта и контрольная сумма.
При ошибке установки восстанавливаются предыдущие файлы.
При ручной установке start-hlcoop.cmd обновляет только файлы мода.
Прямой запуск через hl.exe или Steam эту проверку не вызывает.

Выбранная папка игры и журнал запускателя хранятся в
%LOCALAPPDATA%\HalfLifeCoop. Сам EXE остаётся там, куда вы его положили.

Исходная база — Half-Life SDK от Valve: https://github.com/ValveSoftware/halflife
Лицензия SDK и уведомления об авторских правах сохранены в исходниках проекта.
