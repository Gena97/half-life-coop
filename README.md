# Half-Life Co-op

Мод для совместного прохождения оригинальной Half-Life. Рассчитан на двух игроков, но можно начать одному и подключить друга позже. Есть выбор главы или отдельной карты, общие сохранения и возрождение у контрольных точек.

Мод ещё в разработке. Полное прохождение кампании вдвоём пока не проверено, на переходах и в сюжетных сценах могут встречаться ошибки.

## Установка

Нужны Windows и оригинальная **Half-Life из Steam**. Half-Life: Source не подходит.

1. Закрой игру
2. Скачай `HLCoopLauncher.exe` из [Releases](https://github.com/Gena97/half-life-coop/releases)
3. Положи EXE куда удобно, например на рабочий стол, и открой его — запускатель найдёт Half-Life, установит мод и запустит игру

Для следующих запусков открывай этот же EXE. Он остаётся на своём месте и сам обновляется. Ярлыки не создаются. Если игра не найдена или установлена в нескольких местах, запускатель предложит выбрать папку с `hl.exe` и `valve`.

Вручную установить мод тоже можно: распакуй `hlcoop-…-win32.zip` рядом с `hl.exe` и открой `hlcoop/start-hlcoop.cmd`.

В меню выбери **New co-op campaign**, чтобы начать с поездки в Чёрную Мезу. Оружие и костюм появятся по ходу сюжета.

Запускатель добавляет `-insecure`: сервер работает без VAC.

## Как играть с другом

У обоих должна быть одинаковая версия мода и запущен Steam.

Каждый игрок открывает свой `HLCoopLauncher.exe`. Хозяин начинает или продолжает игру. Друг тоже запускает мод, затем принимает приглашение через Steam или присоединяется через список друзей. При создании сервера оставьте включённым **Steam Networking**.

Для игры по локальной сети выключите Steam Networking в настройках сервера. Друг подключается через консоль:

```text
connect IP_ХОЗЯИНА:27015
```

## Главы и сохранения

Чтобы начать с нужного места, открой `Esc → Выбрать главу или карту → Game / Игра`. В списке есть 19 глав и все 96 карт кампании. Здесь же выбираются сложность и число игроков.

Выбор главы начинает новую сессию. Быстрое и именованные сохранения остаются, а автосохранение и контрольная точка со временем перезапишутся.

Сохранять и загружать игру может хозяин:

- **F6** — сохранить всю сессию
- **F7** — загрузить быстрое сохранение
- **Continue co-op game** в меню — продолжить быстрое сохранение
- **Load co-op autosave** — загрузить автосохранение

Для отдельного слота используй `coop_save chapter1`, для загрузки — `coop_load chapter1`. Загрузка возвращает всю группу и мир к сохранённому состоянию.

Файлы сохранений лежат в `Half-Life/hlcoop/save`. Быстрое сохранение называется `coop_quick.hcs`.

## Настройки

**Урон по товарищам включён по умолчанию.** Хозяин может отключить его командой:

```text
mp_friendlyfire 0
```

Чтобы оставить этот выбор после смены карты, замени `mp_friendlyfire 1` на `mp_friendlyfire 0` в установленном `hlcoop/coop.cfg`.

Если мышь не даёт повернуться на полный круг, попробуй команду `m_rawinput 0` в консоли (`~`).

## Обновления

`HLCoopLauncher.exe` проверяет новые версии в GitHub Releases перед игрой. Обновляются и мод, и сам EXE в той папке, куда ты его положил. Сохранения и настройки остаются. Без интернета можно установить встроенную версию и играть в уже установленную.

Начиная с 0.4.10, установка и обновление работают внутри самого EXE, без запуска PowerShell. Обновление принимается только с подписью ключом проекта. Сертификата издателя Windows у проекта пока нет: подпись обновлений и Authenticode — разные вещи.

При ручной установке `start-hlcoop.cmd` обновляет только файлы мода. EXE распознаёт уже установленный мод, переустанавливать его вручную не нужно.

Выбранная папка игры и журнал запускателя хранятся в `%LOCALAPPDATA%\HalfLifeCoop`. Сам EXE остаётся там, где ты его сохранил.

Прямой запуск `hl.exe` или запуск через Steam эту проверку не вызывает.

Адрес репозитория для EXE задаётся при сборке. Файл `hlcoop/update.json` относится к старому способу запуска через CMD. Подробнее — в [инструкции по автообновлению и выпуску релизов](docs/AUTO_UPDATE.md).

## Если нашёл ошибку

Напиши в [Issues](https://github.com/Gena97/half-life-coop/issues), на какой карте возникла проблема и что происходило перед ней. Если ошибка повторяется после загрузки сохранения, укажи это тоже.

Отдельные запуски всех 96 карт проверялись, но это не прохождение кампании. Ещё нужно проверить все сюжетные условия, переходы и сохранения с двумя настоящими игроками. Техническое описание проверки переходов — в [docs/TRANSITION_CHECK.md](docs/TRANSITION_CHECK.md).

## Сборка из исходников

Нужны Visual Studio 2022 или Build Tools 2022 с MSVC v143 для x86/x64 и Windows SDK.

Из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-launcher.ps1
```

Готовые EXE, ZIP и SHA256 появятся в `artifacts`. Для публикации дополнительно нужны подпись манифеста обновления и успешная проверка Defender — порядок описан в [docs/AUTO_UPDATE.md](docs/AUTO_UPDATE.md). Скрипт `scripts/install.ps1` устанавливает собранный мод в Half-Life, сохраняя существующие настройки.

## Лицензия

Мод основан на [Half-Life SDK от Valve](https://github.com/ValveSoftware/halflife). Лицензия SDK разрешает бесплатное распространение модификаций с сохранением обязательных уведомлений. Её текст находится в [LICENSE](LICENSE), сведения об исходной базе — в [docs/UPSTREAM.md](docs/UPSTREAM.md).

Ресурсы Half-Life в архив не входят: мод использует файлы установленной игры.

Запускатель использует nlohmann/json под лицензией MIT. Её текст включён в EXE и доступен через пункт «Лицензии» в системном меню окна.
